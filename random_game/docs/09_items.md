# 09 — Items

## Prinsip

Tidak ada sistem inventory umum. Item muncul pada HUD atau dialog ketika relevan. Tujuannya mengurangi menu, balancing, serta aset.

## Item Rilis

### Selendang Ibu

- Diberikan sebelum serangan.
- Tidak dapat dibuang dan tidak memberi statistik.
- Muncul pada cutscene, transisi, dan Epilog.

### Pahat Sastro

- Sesuai pekerjaan Sastro sebagai tukang kayu.
- Digunakan dalam tutorial memperbaiki pagar.
- Diletakkan Sutrisno di makam pada Epilog.

### Daftar Nama Joyo

- Berisi nama anak-anak pengungsi yang ingin ia ajar.
- Menjadi setup kematian Joyo dan payoff ruang belajar pada Epilog.
- Tidak memberi efek statistik.

### Pesan Peringatan

- Objective utama Q-03.
- Ditampilkan sebagai ikon, bukan item yang dapat hilang.

### Perban

- Memulihkan sebagian HP.
- Jumlah sangat terbatas dan dapat digunakan pada diri sendiri atau warga tertentu.

### Senapan dan Amunisi

- Diberikan Pak Darma sebelum jalur berbahaya.
- Satu-satunya senjata api pemain.
- Amunisi terbatas; identitas model menunggu verifikasi sejarah.

### Air dan Mainan

- Digunakan pada Q-02 serta OP-01.
- Tidak memerlukan menu inventory.
