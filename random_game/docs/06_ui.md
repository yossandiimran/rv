# 06 — UI

## Prinsip

- Sesedikit mungkin elemen agar cerita dan pixel art tetap dominan.
- Nyaman untuk desktop dan layar sentuh landscape.
- Estetika kertas, tinta, kain, dan warna kusam era 1940-an tanpa mengorbankan keterbacaan.
- Informasi penting tidak hanya dibedakan melalui warna.

## Layar Rilis

### Title

Mulai · Lanjutkan · Pengaturan · Kredit · Catatan Historical Fiction.

### HUD

- HP.
- Amunisi ketika senjata tersedia.
- Prompt interaksi.
- Objective pendek.
- Indikator terlihat/curiga saat stealth.

HUD menghilang pada adegan keluarga, cutscene, dan momen hening.

### Dialog

Portrait, nama, teks, indikator lanjut, dan maksimal tiga pilihan. Teks harus nyaman dibaca tanpa menutupi ekspresi karakter.

### Pause/Settings

Lanjutkan · Mulai checkpoint · Pengaturan · Kembali ke title.

Tidak ada inventory, equipment, party, skill tree, map besar, camp, crafting, atau journal kompleks pada versi rilis.

## Mobile

- Virtual joystick kiri.
- Tombol interaksi/konfirmasi kanan.
- Tombol serang hanya muncul ketika senjata tersedia.
- UI diuji pada beberapa rasio layar; area aman mencegah tombol terpotong.

## Aksesibilitas

- Ukuran serta kecepatan teks.
- Subtitle.
- Skip dan replay cutscene.
- Opsi mengurangi screen shake, flash, dan getaran.
- Content warning untuk serangan, kematian keluarga, api, dan suara tembakan.
- Kontrol keyboard serta gamepad dasar jika waktu memungkinkan; touch tetap wajib.

## Motif Keluarga

Selendang Ibu muncul sebagai ikon kecil pada transisi bagian dan Epilog, bukan sebagai menu inventory atau collectible.
