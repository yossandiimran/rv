# 05 — Gameplay

## Format

Narrative action RPG 2D top-down berdurasi 2,5–3 jam. Empat area kecil dibuka berurutan dan dapat dieksplorasi secara terbatas. Tidak ada open world atau grinding.

## Core Loop

Explore → Talk → Help → Stealth/Combat → Story

## Sistem Inti

### Movement dan Interaksi

- Bergerak empat arah.
- Berinteraksi dengan NPC, pintu, benda, objective, dan warga yang perlu dibantu.
- Sprint singkat hanya jika dibutuhkan pacing.

### Dialog

- Dialog linear dengan beberapa pilihan nada.
- Flag sederhana memunculkan callback dan variasi Epilog.
- Tidak ada relationship atau reputation numerik.

### Quest

- Lima quest utama.
- Dua aktivitas opsional singkat yang memperdalam warga.
- Objective dan checkpoint jelas tanpa quest log kompleks.

### Stealth

- Musuh mempunyai rute, jarak pandang, status curiga, dan alarm.
- Pemain dapat memanfaatkan bangunan, pohon, serta rintangan untuk memutus pandangan.
- Tidak ada takedown stealth kompleks.

### Combat

- Satu senapan dengan amunisi terbatas.
- Satu serangan jarak dekat sederhana.
- Perban untuk memulihkan HP.
- Dua encounter pendek dan tidak ada boss.
- Tidak ada grenade, dodge roll, skill tree, dedicated cover system, atau variasi senjata.

### Companion

Darma, Bima, Sari, Joyo, Karso, dan Lastri bergerak melalui script pada adegan tertentu. Mereka bukan party yang dapat diatur dan tidak membutuhkan AI combat umum. Joyo menjadi companion utama pada Q-03; karakter lain memakai waypoint serta trigger khusus scene.

### Save

- Autosave pada pergantian bagian dan checkpoint.
- Continue dari menu utama.
- Satu penyimpanan lokal cukup untuk rilis pertama.

## Struktur Waktu Bermain

- 35–40 menit: rumah dan kampung.
- 30–35 menit: serangan dan pelarian.
- 45–50 menit: pengungsian dan misi kurir.
- 40–45 menit: evakuasi final.
- 10 menit: Epilog dan credit.

## Definition of Done

Game dianggap selesai jika pemain dapat memainkan cerita dari title sampai credit tanpa blocker, seluruh dialog utama tampil benar, checkpoint bekerja, kontrol desktop/mobile dapat digunakan, dan ending memberikan penutup emosional.

Fitur tambahan tidak boleh menunda alur utama yang lengkap.
